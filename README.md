# dotfiles

Personal machine: CachyOS + niri + noctalia. Managed with **GNU stow**: every
top-level directory is a package, and its contents mirror the `$HOME` tree.

```
fish/.config/fish/           →  ~/.config/fish/
ghostty/.config/ghostty/     →  ~/.config/ghostty/
lazygit/.config/lazygit/     →  ~/.config/lazygit/
nvim/.config/nvim/           →  ~/.config/nvim/
niri/.config/niri/user_cfg/  →  ~/.config/niri/user_cfg/
noctalia/.config/noctalia/   →  ~/.config/noctalia/
git/.gitconfig               →  ~/.gitconfig
git/.gitignore               →  ~/.gitignore
```

## Why stow

stow creates **symlinks**. The file I edit under `~/.config` *is* the file in the
repo, there is no copy to resynchronise, so drift is structurally impossible.
All that's left is a `git commit`, which is `./sync.fish`.

And it is **opt-in per package**: `stow nvim` on one machine, not on the other.
No global "desired vs actual" state, so nothing to diverge from.

## Usage

```fish
./sync.fish                     # commit (and push if a remote exists)
./sync.fish "feat: keymaps"     # with a message
```

## Adding / removing a package

```fish
mkdir -p newthing/.config/newthing
mv ~/.config/newthing/* newthing/.config/newthing/
rmdir ~/.config/newthing
stow -t ~ newthing
```

To remove: `stow -D -t ~ newthing` drops the symlink, the files stay here.

On a fresh machine: clone, then `stow -t ~ fish ghostty lazygit nvim niri noctalia git`
(or just the packages you want). System packages are not managed here, I
install them as I need them.

## niri: only `user_cfg/` lives here

`~/.config/niri/` is managed by cachyos + noctalia, and that suits me. These
stay as real files, unversioned, updated by the packages:

- `cfg/*.kdl`: cachyos presets
- `config.kdl`: the `include` lines (plus noctalia's own `binds{}` block on
  the machine where noctalia v5 injected one)
- `noctalia.kdl`: generated by noctalia at runtime
- `monitor.kdl`: generated by nwg-displays, describes *this* machine (absolute
  x/y positions), not portable by nature

Only `user_cfg/` is mine, so it is versioned: keybinds, input, layout, rules.

Two things to know about the include order in `config.kdl`: `user_cfg/` is
included after `cfg/`, which is what makes my overrides win over the cachyos
presets. But noctalia's `binds{}` block sits *after* the includes, so it wins
over mine: `Mod+Space` and `XF86PowerOff` are declared in both places and it is
noctalia's version that is live.

`user_cfg/_my-display.kdl` is entirely commented out and duplicates what
`monitor.kdl` does. It stays only because `config.kdl` includes it by name.

## What each package expects on the system

System packages are not managed here, but the configs assume a few binaries.
Missing ones degrade gracefully (fish hooks are guarded, LSPs only start when
their binary exists), except where marked **required**.

| Package | Needs |
|---------|-------|
| nvim | **neovim >= 0.12** (`vim.pack`), **tree-sitter-cli** (parsers), **cargo** (blink native lib, rust-analyzer via rustup), `@github/copilot-language-server` (`pnpm add -g`; its `bin` entry is broken so no shim is created, nvim finds the native binary in pnpm's store itself, or symlink it into `~/.local/bin`), codelldb (debug, else lldb-dap), taplo / stylua / prettier (formatters) |
| git, lazygit | git-delta (diff pager) |
| fish | fzf, direnv, zoxide, starship |
| niri, noctalia | noctalia v5, wtype (Mod+C/V/X) |

Copilot is not a plugin anymore: nvim 0.12's native `vim.lsp.inline_completion`
talks to the official language server. It reuses the token copilot.lua left in
`~/.config/github-copilot/`, `:LspCopilotSignIn` if it ever needs redoing.

## git: identity vs shared settings

`git/.gitconfig` carries the personal identity and includes
`~/.gitconfig-shared`, which holds everything identity-free (delta, merge and
rebase defaults). The work laptop keeps its own `~/.gitconfig` (other email,
gpg signing) and is **not** stowed with `git`; it only adds:

```
[include]
  path = ~/.config/dotfile/git/.gitconfig-shared
```

## Deliberately not here

- **system packages**: I install what I need when I need it
- **noctalia GUI state** (`~/.local/state/noctalia/settings.toml`): written by
  the Settings UI, wins over `config.toml`. Only the declarative `config.toml`
  is versioned (both machines run v5 since 2026-09-14).
- **`~/.ssh`**, Bitwarden session, browser profiles
